# Städbi Hemtjänst

Responsivt designförslag för Städbi Hemtjänst i Knivsta. Öppna `dist/index.html` i en webbläsare. Ingen installation eller byggprocess behövs.

## Innehåll
Hemstädning, storstädning, presentation, arbetsgång, FAQ och interaktivt offertformulär i demoläge. Formuläret skickar eller lagrar inga uppgifter. Kontaktuppgifter, tjänster och villkor behöver godkännas av företaget före skarp lansering. Inga priser, betyg eller garantier har hittats på.

Textunderlag: användarens inklistrade beskrivning från Things Review. Bilder: externa inspirationsbilder från Unsplash. Typsnitt: Google Fonts (DM Sans, Manrope). Bilderna föreställer inte företagets personal eller dokumenterade uppdrag. Sidan har noindex för att markera demonstrationsstatus.

## Publicering
Statisk webbplats i `dist/`. GitHub Pages kan använda medföljande arbetsflöde när Pages är inställt på GitHub Actions. Sites använder `.openai/hosting.json`.
